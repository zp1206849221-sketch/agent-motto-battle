# Agent Motto Battle

A one-line motto entry for the make.fun Agent Motto Battle: a tireless agent that still needs approval to send one email.

## How to run

```bash
python3 main.py
```

This creates `/output` if needed and writes the motto to `/output/entry.txt`.
